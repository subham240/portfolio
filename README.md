# Subham Acharya — AI & ML Engineer Portfolio

A personal portfolio for **Subham Acharya**, AI & Machine Learning Engineer, inspired by the high-craft editorial design of Nova.

## 🚀 Key Features

- **Editorial Art Direction**: Warm off-white canvas (`#faf7f2`), crisp typography (Playfair Display + Inter), amber gold accents (`#d4a853`), and deep charcoal text (`#1a1a18`).
- **Smooth Animations**: Staggered hero entrance, line-by-line word reveals, scroll-triggered section reveals, and micro-interactions on project cards.
- **Custom Floating Cursor**: Desktop-only interactive pill badge on project previews with `requestAnimationFrame` interpolation.
- **Accessible & Responsive**: Fully supports `prefers-reduced-motion`, responsive mobile navigation drawer, and semantic HTML5.
- **Verified Featured Projects**:
  1. **Medical Lab Report Assistant** ([Live App](https://medical-lab-report-assistant-3jtf93nk6a9nszarn4mdnj.streamlit.app/) | [GitHub](https://github.com/subham240/medical-lab-report-assistant))
  2. **SnapClass — AI Attendance System** ([Live App](https://snapclass-landing-hazel.vercel.app/) | [GitHub](https://github.com/subham240/snapclass-app))
  3. **Smart Customer Segmentation System** ([Live App](https://smartcart-segmentation-zuxhyiwtapkld2vhnutyue.streamlit.app/) | [GitHub](https://github.com/subham240/smartcart-segmentation))

## 🛠️ Tech Stack

- **Framework**: Astro 4 LTS
- **Styling**: Tailwind CSS
- **Components**: React & Astro
- **Icons**: Lucide Icons
- **Deployment**: GitHub Pages / Vercel / Netlify

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build static production bundle
npm run build

# Preview production build locally
npm run preview
```
